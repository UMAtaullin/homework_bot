# homework_bot (Проект создан в рамках учебного курса Яндекс.Практикум)

### Описание проекта:

Телеграм-бот для отслеживания статуса проверки домашней работы на Яндекс.Практикум: взята ли
ваша домашка в ревью, проверена ли она, а если проверена — то принял её ревьюер или вернул на доработку.


### Стек технологий

* Python 3.9
* python-dotenv 0.19.0
* python-telegram-bot 13.7

### Установка проекта из репозитория

1. Клонировать репозиторий:

   ```python
   git clone git@github.com:UMAtaullin/homework_bot.git
   ```

2. Установить виртуальное окружение для проекта:

   ```python
   python3.9 -m venv venv
   ```

3. Активировать виртуальное окружение для проекта:

   ```python
   # для OS Lunix и MacOS
   source venv/bin/activate

   # для OS Windows
   source venv/Scripts/activate
   ```

4. Установить зависимости:

   ```python
   python3 -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

5. Записать в переменные окружения (файл .env) необходимые ключи:

   ```python
   * токен профиля на Яндекс.Практикуме
   * токен телеграм-бота
   * свой ID в телеграме
   ```

6. Запустить проект:

   ```python
   python homework.py
   ```
